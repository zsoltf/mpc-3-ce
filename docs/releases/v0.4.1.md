# MPC 3 CE v0.4.1

For MPC Live II with MPC 3.10 Gen1. The image builder also makes v0.3.0
from the MPC 3.9.1 update.

## What's new

- **X-Touch Mini mixing.** Six knob modes: Volume, Pan, Q-Links 1-8,
  Q-Links 9-16, Sends and Inserts. Rings follow changes made on the MPC.
- **Independent track buttons.** Select, mute, solo or arm eight tracks,
  whatever the knobs are doing. Change banks with B + Rewind/Forward.
- **Quick menus and transport.** Tap A or B to cycle modes, or hold one to
  choose directly. Save and Add Track are in the A menu. Undo, Redo, Loop,
  Stop, Play and Record stay on the bottom row.
- **Mini visual guide.** See the normal and held layouts and print a button
  reference in the [Mini guide](https://mpc3ce.com/mini-guide.html).

## Install

[Build your image](https://mpc3ce.com/builder.html) from Akai's official
`MPC-3.10.0-Gen1-update.img`. Install by USB Drive Update. Preferences > Info
then shows `MPC 3 CE 0.4.1`.

Connect the Mini in MC mode. Turn Track, Global and Control off for
`X-TOUCH MINI MIDI 1` in MIDI/Sync, then press Detect in Preferences > CONTROLLERS.
Reconnect starts with Volume knobs and Select track buttons.

The Pd/Cardinal SD bundle is unchanged. If it is already installed, keep it.
Otherwise download the [v0.4.0 SD plugin bundle](https://github.com/zsoltf/mpc-3-ce/releases/tag/v0.4.0)
and copy its `MPCLEARN` folder to the SD card root with the MPC off.

## Known limits

- Record in the Mini's top-row menu arms tracks; bottom-row Record controls
  transport recording. Missing or unsupported tracks stay dark.
- Finish insert plug-in choosers on the MPC. Q-Link and Send knob pushes do
  nothing; Volume and Pan pushes select a track without resetting its value.
- Online Update replaces CE with stock firmware. Keep the official Akai update
  for recovery, and back up projects before changing firmware versions.
- The existing controller and plugin limits in the
  [v0.4.0 notes](https://github.com/zsoltf/mpc-3-ce/blob/main/docs/releases/v0.4.0.md)
  still apply. Other Gen1 MPC models are untested; Gen2 and Force are unsupported.

## Source code

The unchanged SD plugin bundle contains GPL software: Cardinal, Pure Data with
libpd, and Debian 12 libraries. Its complete source is the pinned upstream code
in [release/sources](https://github.com/zsoltf/mpc-3-ce/tree/v0.4.0/release/sources)
plus the changes and build scripts in the published v0.4.0 source.
See [Build from source](https://github.com/zsoltf/mpc-3-ce/blob/v0.4.0/docs/BUILDING.md#cardinal-and-pd-plugins).
The current CE source is on [main](https://github.com/zsoltf/mpc-3-ce).

Do not share generated Akai firmware images.
