# MPC 3 CE v0.4.0

For MPC Live II with MPC 3.10 Gen1. The image builder
also still makes v0.3.0 from the MPC 3.9.1 update.

## What's new

- **MPC 3.10.** CE runs on Akai's 3.10 firmware: X-Touch, Launchpad X and
  Pro Mk3, Launch Control XL3, Detect, Global MIDI Learn, and the Pd and
  Cardinal touch editors.
- **Touchscreen-free clip editing.** Copy and delete clips or rows, double events,
  capture playing clips into a new row, and use native Undo/Redo on Launchpad X
  and Pro Mk3. Pro Mk3 also has a direct Quantise shortcut. The
  [visual guide](https://mpc3ce.com/launchpad-guide.html) shows the controls.
- **X-Touch Save.** Save the project with its dedicated button; unnamed projects
  open MPC's normal save dialog.
- **One builder for both.** Choose `MPC-3.10.0-Gen1-update.img` or
  `MPC-3.9.1-Gen1-update.img`; the builder recognises the file and makes the
  matching image.

## Install

Build the image in your browser from your own official Akai 3.10 update.
Download and unzip `mpc-ce-v0.4.0-sd-plugins.zip` from this release, then copy
its `MPCLEARN` folder to the SD card root with the MPC off. Set each
controller's mode and MIDI routing from the controller guide, then press Detect
in Preferences > CONTROLLERS.

After installation, Preferences > Info shows `MPC 3 CE 0.4.0`.

## Known limits

- Online Update replaces CE with stock MPC. To return, build the image again
  from the same Akai update and install it by USB.
- Back up projects before moving between 3.9.1 and 3.10: Akai has not said
  whether 3.10 projects open in 3.9.1.
- Legacy User Level Velocity MIDI mappings need to be assigned again in
  Global MIDI Learn after moving to 3.10.
- X-Touch Shift+jog does not extend the loop in Arrange. Use the MPC's
  Shift+wheel for this.
- Note selection uses MPC's native Undo history. Undo may first undo the
  selection before a musical edit; selecting a note also clears Redo.
- The v0.3.0 limits for Cardinal, Launchpad drum colours, track colour changes,
  the XL3 Pad mixer and Akai profiles still apply.

## Source code

The SD plugin bundle contains GPL software: Cardinal, Pure Data with libpd, and
Debian 12 libraries. Its complete source is the upstream code below plus the
changes and build scripts in this repository at tag `v0.4.0`; see
[Build from source](https://github.com/zsoltf/mpc-3-ce/blob/v0.4.0/docs/BUILDING.md#cardinal-and-pd-plugins).

- [Cardinal](https://github.com/DISTRHO/Cardinal) at
  `0a530b73273afc914ec71a78e9165cd28c53b599`, with its submodules at the
  revisions in `release/sources/cardinal-sources.json`.
- [libpd](https://github.com/libpd/libpd) at
  `ba0dc63262901d658af8bbda5e619a60fa975e78` with
  [Pure Data](https://github.com/pure-data/pure-data) at
  `f009fd8d7b537e209e09898d487fdf1bf547da2b`.
- Debian source packages from [snapshot.debian.org](https://snapshot.debian.org/),
  with exact versions and SHA-256 in `release/sources/debian-sources.json`.

Keep the official Akai update for recovery. Do not share generated Akai images.
