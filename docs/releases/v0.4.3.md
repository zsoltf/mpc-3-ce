# MPC 3 CE v0.4.3

For MPC Live II with MPC 3.10 Gen1. The image builder also makes v0.3.0
from the MPC 3.9.1 update.

## What's new

- **Background sampling.** Record while Main or another screen stays open.
  On Live II, hold **Shift** and press **Erase** to start immediately; repeat
  to stop and open native Keep/Discard. Recording and Stopped banners show
  the sampler state.
- **Controller sampler shortcuts.** X-Touch, X-Touch Mini, Launchpad and
  Launch Control XL3 can arm, start and stop sampling, with state lights.
  See the [sampling guide](https://github.com/zsoltf/mpc-3-ce/blob/main/docs/controller-programs.md#sampler-controls-on-mpc-310).
- **Drum-pad MIDI mute.** Pad mute and solo also affect outgoing MIDI notes.
  Muting stops held notes and blocks new notes; unmuting does not replay them.

## Install

[Build your image](https://mpc3ce.com/builder.html) from Akai's official
`MPC-3.10.0-Gen1-update.img`. Install by USB Drive Update. Preferences > Info
then shows `MPC 3 CE 0.4.3`.

The Pd/Cardinal SD bundle is unchanged. Keep your existing bundle, or download
[`mpc-ce-v0.4.3-sd-plugins.zip`](https://github.com/zsoltf/mpc-3-ce/releases/tag/v0.4.3)
and copy its `MPCLEARN` folder to the SD card root with the MPC off.

## Known limits

- Set the input and recording options on Sampler before starting in the
  background. Leaving the Sampler page retains its normal stop behavior.
  Finish Keep/Discard on the MPC.
- The MPC Shift+Erase shortcut is specific to Live II. Other models keep
  their native button behavior.
- MIDI 1.0 cannot distinguish simultaneous voices sharing one output port,
  channel and pitch.
- Online Update replaces CE with stock firmware. Keep Akai's official update
  for recovery and back up projects before changing firmware versions.
- Existing controller and plugin limits in the
  [v0.4.2 notes](https://github.com/zsoltf/mpc-3-ce/blob/main/docs/releases/v0.4.2.md)
  still apply. Other Gen1 models are untested; Gen2 and Force are unsupported.

## Source code

The unchanged SD plugin bundle contains GPL software: Cardinal, Pure Data with
libpd, and Debian 12 libraries. Its complete source is the pinned upstream code
in [release/sources](https://github.com/zsoltf/mpc-3-ce/tree/v0.4.0/release/sources)
plus the changes and build scripts in the published v0.4.0 source.
See [Build from source](https://github.com/zsoltf/mpc-3-ce/blob/v0.4.0/docs/BUILDING.md#cardinal-and-pd-plugins).
The current CE source is on [main](https://github.com/zsoltf/mpc-3-ce).

Do not share generated Akai firmware images.
