# MPC 3 CE v0.3.0

The Controller Edition, for MPC Live II with MPC 3.9.1 Gen1.

## What's new

- **Detect.** Preferences > CONTROLLERS > Detect adds every connected X-Touch,
  X-Touch Mini, Launchpad X, Launchpad Pro Mk3 and Launch Control XL3 that is
  not set up yet.
- **Launchpad X and Pro Mk3 clips.** Launch clips, scenes and Arrangement,
  record into empty slots and stop tracks. Clip lights follow the MPC clip
  launcher in your track colours: the playing clip pulses white, queued clips
  flash, recording pulses red.
- **One Launchpad layout.** Session shows clips, Note (X) or Sequencer (Pro)
  edits drum steps, and Custom opens the mixer pages: Volume, Pan, Sends and
  Device. Pan pads have an exact centre, lit white.
- **Drum steps.** 64 steps for one sound or 16 steps for four, with playhead and
  MPC Undo/Redo. Press the step-view button again to switch. Hold it and press
  a clip to program that clip without launching it; an empty slot gets a new
  clip. Two Launchpads can work together, one on clips and one on drums.
- **Pro Track Select row.** It selects tracks. Record Arm, Mute, Solo and Stop
  Clip turn it into per-track buttons: tap to keep the mode, hold for a moment.
  Stop Clip stops clips and never stops the MPC.
- **Launch Control XL3.** Track and drum-pad mixing, sends, Q-Links and effect
  pages in DAW mode. Knob lights show each track's MPC colour. Shift + a
  track's Select button selects it; a Drum track opens the pad mixer.
- **X-Touch meters** stay live while you use other controllers, without flicker.
- **Pd and Cardinal Synth/FX** with touchscreen patch editing and project
  recall, installed from an SD-card plugin bundle. Ripples and Plateau use less
  CPU.
- More MCU/HUI and Akai controller profiles, set up by hand with Add. Hardware
  coverage varies; see the controller guide.

X-Touch control, Global MIDI Learn, USB mouse editing and Shift + data-wheel
note selection remain.

## Install

Build the image in your browser from your own official Akai update. Download
and unzip `mpc-ce-v0.3.0-sd-plugins.zip` from this release, then copy its
`MPCLEARN` folder to the SD card root with the MPC off. Set each controller's
mode and MIDI routing from the controller guide, then press Detect in
Preferences > CONTROLLERS.

Preferences > Info still shows `MPC CE v0.2.6`. Use the v0.3.0 filenames and
checksums to identify this release.

## Known limits

- Requires the MPC 3.9.1 Gen1 update; MPC 3.10 is not supported yet. Online
  Update to 3.10 replaces CE with stock MPC; to return, build the image from
  the 3.9.1 update and install it by USB. Back up projects first: Akai has not
  said whether 3.10 projects open in 3.9.1.
- Cardinal MIDI and Terrorform play up to four voices. Demanding Cardinal
  patches can still overload audio, with no automatic protection; avoid the
  Waves example.
- Launchpad drum steps use a fixed CE colour palette, not MPC pad colours.
- A changed track colour may only show on Launchpad and XL3 lights after the
  project is reloaded.
- The Controllers page lists up to 12 external MIDI ports; each input or output
  port of every connected MIDI device counts. With more connected, unplug a
  device to add or edit controllers.
- XL3 Pad mixer covers volume, pan, Solo and Mute. Its Control mode uses the top
  encoder row only.
- Akai profiles need a saved program on the controller; CE does not upload
  programs. Some compact MCU/HUI and extender workflows are untested.
- Named Cardinal host-parameter controls are not included. If a controller Save
  stalls, save on the MPC.
- Other MPC models, controller reconnects during playback and long sessions
  have limited testing.

## Source code

The SD plugin bundle contains GPL software: Cardinal, Pure Data with libpd, and
Debian 12 libraries. Its complete source is the upstream code below plus the
changes and build scripts in this repository at tag `v0.3.0`; see
[Build from source](https://github.com/zsoltf/mpc-3-ce/blob/v0.3.0/docs/BUILDING.md#cardinal-and-pd-plugins).

- [Cardinal](https://github.com/DISTRHO/Cardinal) at
  `0a530b73273afc914ec71a78e9165cd28c53b599`, with its submodules at the
  revisions in `release/sources/cardinal-sources.json`.
- [libpd](https://github.com/libpd/libpd) at
  `ba0dc63262901d658af8bbda5e619a60fa975e78` with
  [Pure Data](https://github.com/pure-data/pure-data) at
  `f009fd8d7b537e209e09898d487fdf1bf547da2b`.
- Debian source packages from [snapshot.debian.org](https://snapshot.debian.org/),
  with exact versions and SHA-256 in `release/sources/debian-sources.json`.

Keep the official Akai update for recovery. Do not share generated Akai images.
