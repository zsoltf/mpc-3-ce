Launchpad visual guide

A function-by-function Launchpad guide for MPC 3 CE. Choose your controller, then follow the numbered buttons, pads and result. Quantise is available as a direct shortcut on Pro Mk3.

Full controller reference
Your Launchpad

Start in Session. The diagrams use example clips in numbered scenes: the very first visible row is Arrangement on the first page, and editing gestures skip it. Arrows page tracks or rows. Each Launchpad keeps its own view and choices.

Orange outline: holdYellow LED: copy sourceMint ring: press here

Numbers and outlines show your presses; pad colours show representative controller behaviour in an example project, not a live MPC connection. Dark pads are empty, ready clips use track colours, playing clips pulse white, recording pulses red and overdub pulses amber. Queued actions flash. The top clip row is Arrangement; editing examples use numbered scenes below it.

A short white target flash acknowledges that MPC accepted an edit. Normal clip lights return after about half a second. MPC settings can leave contents unchanged even when an action is accepted.

CE v0.4.0 / MPC 3.10 / Session

Quantize

Use current MPC Timing Correct settings on the chosen clip.

Launchpad Pro Mk3

3 Result

MPC retains its current Type, Events scope (All / Selected / Range), timing and groove settings. Timing Correct must be on, as for MPC's Do It; when it is off, events stay unchanged. For audio clips, use Start; End, Length and Legato apply to MIDI notes only.

Connection and Save

These editing controls use MPC 3.10. Select LPX MIDI or LPProMK3 MIDI, the ordinary MIDI port. In MPC MIDI/Sync, turn Track, Control and Global off for that selected Launchpad input; CE receives it independently. Keep other musical and clock routes as needed. Disable the controller row before unplugging to restore its prior hardware mode.

The dedicated X-Touch Save key saves the project. An unnamed project opens MPC's normal save dialog. MPC owns each edit's limits and Undo/Redo.
