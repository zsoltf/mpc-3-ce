X-Touch Mini guide

Control volume, pan, Q-Links, sends and inserts. Use the top buttons to select, mute, solo or arm tracks. Hold A for knob choices, or B for track-button choices. Transport stays on the bottom row.

For CE v0.4.2 on MPC 3.10. Choose a view below to see what each control does.

Tap to cycle. Hold to choose.

A tap
Volume → Pan → Q-Links 1-8 → Q-Links 9-16 → Sends → Inserts → Volume.
B tap
Select → Mute → Solo → Record → Select. This changes the top track buttons, not the knobs.
Hold a Layer button, then tap a top button
The top row becomes that menu. Release the Layer button to return to track controls. A menu choice never also advances the cycle.
A + top 7 / 8
Save / Add Track. Save uses MPC's normal dialog when a project needs a name.

Navigate without changing modes

B + Rewind / Forward
Previous / next bank of eight tracks, in every knob mode. Select, Mute, Solo and Record always address this track bank.
A + Rewind / Forward
In Q-Links: previous / next native MPC Q-Link mode. In an open insert: previous / next parameter page. No action in other modes.
Rewind / Forward alone
Move by beats; hold to repeat. A modified navigation gesture stays modified until you release its navigation button.
Both Layer buttons held
The A menu takes precedence. Releasing them does not cycle either mode; transport and navigation do not fire while both are held.

In Screen mode, banks follow the page's row or column direction. For Cardinal, Q-Links 1-8 cover the first two columns, top to bottom; 9-16 cover the other two. Choose Inserts again to return to the four-slot list. Finish native plug-in choosers on the MPC. Rings follow MPC values, including touchscreen changes; unavailable targets are dark.

The bottom row stays familiar

Undo · Redo · Rewind · Forward · Loop · Stop · Play · Record

Loop, playback and recording lights describe MPC state. Press Stop again while stopped to return to the start. The master fader always controls master output.

In every knob mode, the normal top row still addresses tracks. Select lights the selected track; Mute lights muted tracks; Solo lights soloed tracks; Record lights armed tracks. Record toggles individual track arming; bottom-row Record controls transport recording. Missing or unsupported tracks stay dark.

Reconnect starts at Volume and Select. Hold A or B to see the current mode in its menu.

Connect in MC mode

  1. Hold the Mini's MC button while connecting USB, as described in its manual. Confirm the MC mode indicator.
  2. In MPC Preferences → MIDI/Sync, turn Track, Global and Control off for X-TOUCH MINI MIDI 1.
  3. Open Preferences → CONTROLLERS and press Detect, or add the X-Touch Mini profile with that input/output pair.

Keep other musical and clock routes unchanged. This layout uses MC mode; it does not rewrite a normal-MIDI preset.
