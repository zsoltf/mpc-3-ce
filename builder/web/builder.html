Build your MPC 3 CE image

Adds motorized faders, clip launching, a step sequencer and hands-on mixing to MPC 3.9.1, plus Pd and Cardinal on the touchscreen and mouse editing. The image is built in your browser from Akai's official file. Nothing is uploaded.

  1. Akai's update file

    Choose MPC-3.9.1-Gen1-update.img from Akai. Other files, including MPC 3.10, are refused.

    How to use the debug build
    1. Leave one writable USB drive connected when you boot the Debug build. It creates MPCLEARN-DIAGNOSTICS/report.txt automatically.
    2. Reproduce the problem. The report updates as evidence arrives.
    3. Retrieve MPCLEARN-DIAGNOSTICS/report.txt after reproducing the problem.
    4. Reflash the standard CE or official image afterward. Use the same step if the report is unavailable.

    SHA-256

  4. Install on your MPC

    1. Copy MPC-3.9.1-Gen1-CE-v0.3.0-update.img to the USB drive, outside any folders. Keep only this update image there. If your browser added (1), remove it to match this filename.
    2. Safely eject the USB drive and connect it to the MPC. Save your work, back up important projects, and connect the power adapter.
    3. Open Menu > Preferences > Info > Update > USB Drive Update, choose the image, and confirm Update or reinstall. Let the MPC restart without turning off its power.
    4. For Pd/Cardinal, download and unzip mpc-ce-v0.3.0-sd-plugins.zip from the matching release. With the MPC off, copy its MPCLEARN folder to the SD card root. Keep that card inserted while using plugins.
    5. After restart, check that Preferences > Info still shows MPC CE v0.2.6 (inherited base label; this download is v0.3.0). See Akai's firmware update walkthrough for the stock update screens.
    6. Set your controllers' modes from the controller guide, plug them in and press Detect in Preferences > CONTROLLERS.

Requirements

  • MPC Live II with the 3.9.1 update. MPC 3.10 is not supported yet; don't use Online Update while you use CE. Other Gen1 MPCs are untested.
  • Your controller in its documented mode, its MPC input set to Track, Global and Control off; see the controller guide. Mouse editing and note selection work without one.
  • An SD card for the optional matching Pd/Cardinal bundle.

Before you flash

  • Your settings and projects are kept.
  • Demanding Cardinal patches can still overload audio.
  • See what's new in v0.3.0 and everything it does.
